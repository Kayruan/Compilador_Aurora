ITENS DA ENTREGA (conforme o enunciado)
------------------------------------------------------------------------------
 1. Arquivo do Flex (.l) .................. src/lexico.l
 2. Arquivo do Bison (.y) ................. src/sintatico.y
 3. Arquivos gerados pelo Flex e Bison .... gerados/lex.yy.c
                                            gerados/sintatico.tab.c
                                            gerados/sintatico.tab.h
                                            (criados ao compilar; veja abaixo)
 4. Demais arquivos para compilar ......... src/aurora.h e src/*.c,
                                            Makefile (Linux), compilar.bat (Windows)
 5. Código de exemplo na linguagem ........ exemplos/codigo_para_executar.txt


COMO COMPILAR E EXECUTAR
------------------------------------------------------------------------------
 Linux (requer flex, bison, gcc e make):
     make                      -> gera os arquivos e compila (./aurora)
     make executar             -> roda exemplos/codigo_para_executar.txt
     make testar               -> roda os testes automáticos

 Windows (requer WinFlexBison e gcc/MinGW):
     compilar.bat              -> gera os arquivos, compila e roda o exemplo
     compilar.bat testar       -> gera os arquivos, compila e roda os testes

 Executar qualquer programa:
     ./aurora  <arquivo>                (Linux)
     aurora.exe <arquivo>               (Windows)
     aurora --arvore <arquivo>          mostra também a árvore sintática

 A pasta gerados/ é criada na compilação (make ou compilar.bat). Depois de
 gerada uma vez, é possível recompilar só com o gcc:
     gcc -Isrc -Igerados -o aurora gerados/*.c src/*.c -lm


ORGANIZAÇÃO DAS PASTAS
------------------------------------------------------------------------------
 src/         código escrito à mão (Flex, Bison e módulos em C, comentados)
 gerados/     arquivos produzidos pelo Flex e pelo Bison
 exemplos/    programas de demonstração na linguagem Aurora
 exercicios/  10 exercícios resolvidos e comentados (material de estudo)
 testes/      corretos.txt (programas que devem funcionar),
              erros.txt (programas com erros propositais) e os scripts de teste
 docs/        documentação em PDF, enunciado e roteiro de apresentação


EXEMPLO DA LINGUAGEM
------------------------------------------------------------------------------
 programa Exemplo {
     funcao dobro(n: inteiro): inteiro {
         retorne n * 2;
     }
     inicio {
         seja a: inteiro = 10;
         seja b: real = a / 4.0;
         escreva("dobro de a =", dobro(a), "e b =", b);
     }
 }

 Saída:  dobro de a = 20 e b = 2.5
